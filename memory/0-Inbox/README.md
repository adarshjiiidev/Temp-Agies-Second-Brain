# Inbox — Triage Instructions

**Purpose:** Raw capture zone. Everything starts here.

## How to Use

1. **Capture:** When you discover something important, save it here immediately as a dated note.
2. **Triage (weekly):** Go through each note and decide:
   - **File to project:** If it's about an active project → move to `1-Projects/<project>/`
   - **File to area:** If it's ongoing knowledge → move to `2-Areas/<area>/`
   - **File to resources:** If it's reference material → move to `3-Resources/<topic>/`
   - **Distill:** If it contains key insights, extract them into a concise summary and link from appropriate MOC
   - **Link:** Add [[wiki-links]] to connect to related notes
   - **Delete:** If it's no longer relevant, delete it
3. **Update MOCs:** After triaging, update relevant Maps of Content with new links.

## Note Format

```markdown
# YYYY-MM-DD HH-MM Description

**Captured:** YYYY-MM-DD HH:MM
**Source:** where this came from
**Tags:** #tag1 #tag2

## Content

What was discovered/learned/observed.

## Why It Matters

Why this is worth keeping.

## Connections

- [[related note 1]]
- [[related note 2]]
```
