# MOCs — Maps of Content

MOCs are narrative index notes that connect related notes together. They're the primary way to navigate the second brain.

## Creating a MOC

1. Identify a topic area
2. Create `MOCs/<Topic>.md`
3. Add overview description
4. Link to key notes with [[wiki-links]]
5. Organize links by subtopics
6. Update as new notes are added

## Example Structure

```markdown
# Topic MOC

## Overview
Brief description of what this topic covers.

## Subtopics
### Subtopic 1
- [[Note 1]]
- [[Note 2]]

### Subtopic 2
- [[Note 3]]

## Related
- [[Related MOC 1]]
- [[Related MOC 2]]

## Recent Additions
- [[Newest Note]]
```
