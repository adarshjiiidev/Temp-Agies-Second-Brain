## 1. Skill Lifecycle

Every reusable skill follows an empirical lifecycle:
```
OBSERVED (Pattern detected in tasks)
   │
   ▼
CANDIDATE (Drafted into SKILL.md template)
   │
   ▼
TESTED (Executed in sandboxed subtask)
   │
   ▼
VERIFIED (Confirmed correct output and failure modes)
   │
   ▼
TRUSTED (Registered into AGIES active skill matrix)
```
